  Streamlit cover source, limit, language priority, manual/auto preference,
  grouping and status. Markdown/TXT/JSONL exports meet the required formats.
  Grouping is a view over one canonical record per video; no P4 extraction,
  graph, research or pack behavior was introduced. Optional JSON/SRT/VTT were

  `workflows.export`, which reuse P1/P2 services.

  Selection fails explicitly for unknown IDs. Full records and all linked source
  manifests preserve metadata, original URLs, timing, observations, conflicts and
  extensions. Required render/provenance fields and manifest hash identities are
  validated before any output writes. Atomic per-file replacement plus temporary
  file cleanup supports safe re-export after failures. Scrape retains successful
  captions and reports source/video failures, with retry policy delegated to P2.

  including the 104 prior regressions and native Streamlit AppTest. No skips,
  failures or errors. Test evidence describes fixture tests and controlled smoke
  accurately and does not claim live source success, remote CI, browser UAT or
  minimum-version coverage. Installed package matches current source.

  unknown fields and source-manifest references; verification/confidence/visual

  Markdown fences protect literal source URLs, transcript text and embedded JSON;
