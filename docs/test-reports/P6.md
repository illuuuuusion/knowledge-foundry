## Review round 1 and fixes

The separate reviewer (docs/reviews/P6.md) requested changes. **B1**: JSONL rows
were read with `splitlines()`, which also splits at U+2028/U+2029/U+0085 that P5
writes raw inside JSON strings, so one such title/statement/label crashed the
whole build. **B2**: a destination at a not-yet-existing `source_dir` or
`source_dir/research/<domain>` was accepted; the research agent then saved bundles
there and the next rebuild deleted them. Non-blocking: N1 crafted labels equal to
another label's hashed stem aborted the build; N2 unbounded P5 quotes copied whole
saved pages; N3 linkify viewers link bare URLs in escaped text; N4 a trailing `#`
run became an ATX closing sequence; N5 rejected bundles still replace the library;
N6 single pages lacked the rules; N7 default destination inside the repo; N8 user
files in a library are deleted on rebuild.

Fixes: rows split on `'\n'` only (B1). `_check` refuses, by realpath and even
before the folders exist, destinations that contain `output_dir` or overlap
`source_dir`, the database folder, `output_dir/graph` or `output_dir/jobs` (B2).
`_names` rehashes plain stems until none clashes with a hashed stem (N1). Quotes
over 300 characters are cut with `…` and flagged `quote_truncated` in the
library's evidence.jsonl (N2). A rule says URLs inside source text are not
sources (N3). `#` is escaped (N4). The report warns per rejected bundle (N5).
Every page carries a one-line rules reminder linking AGENTS.md (N6). N7/N8 stay
documented (README, KNOWLEDGE.md).

Tests: the escaping test is now also the B1 regression (separators in statement,
alias, video title, document title, quote and conflict note; graph copies stay
byte-identical; no separator survives in Markdown). The path test adds the N1
labels (`X`, `x`, `x-<hash of X>`, one level deeper, `index-<hash of Index>`) and
B2 destinations (missing source_dir, research folder, inside data, jobs, graph,
through a symlinked alias of source_dir, output_dir itself and its parent; nothing
is created). The no-transcript test adds a quote equal to a 1,000+ character
saved page (N2). Link test checks the reminder on every page (N6); CLI test the
rejection warning (N5).

Runs:

## Review round 2 and fixes

The reviewer verified B1, B2 and N1–N6 (observed 172 passing tests) and requested
changes for **B3**: the B2 path comparison was exact-string, so on case- or
normalization-insensitive file systems (macOS APFS default, Windows) `--output
<store>/SOURCES`, a case variant of a parent folder or an NFD spelling slipped past
and the research agent's bundle could again be deleted. Non-blocking: **N9** two
crafted labels with equal 8-hex suffixes (found in ~43k tries) abort the build
with a path collision (nothing overwritten); **N10** many short quotes can still
reproduce a whole saved page.

Fixes: `_check` compares `NFC(realpath(path)).casefold()` keys for the destination
and every guarded folder (B3; on case-sensitive systems this only errs toward
refusing). Hashed stems that still clash get the full SHA-256 digest (N9). N10 is
documented as a residual risk (README sharing note, KNOWLEDGE.md).

Tests: the path test adds `SOURCES`, `Sources/research/gpu-repair`,
`DATA/library`, `Output/Jobs/x` and an NFD spelling of an NFC source folder (all
refused, nothing created) and the reviewer's colliding label pair
`x !!?,+!)` / `x !!;,.;,` (built as distinct files). Swapping the round-2 `_check`
or `_names` back into the module makes this test fail (4 B3 subtests plus the N9
collision). Reviewer reproductions: `r2_overlap.py` and `r2_case.py` now refuse
every overlapping variant (a library next to the store still builds);
